# Sistema de Gestión de Bar - Proyecto Académico de Angel Chicaiza, Angelo Conteron y Jannys Garrido

Este repositorio contiene el desarrollo del sistema de gestión para un bar, elaborado como parte de la asignatura Diseño de Aplicaciones y Servicios de Internet[cite: 32].
El proyecto se desarrolla usando ASP.NET Core Web API como backend y Blazor WebAssembly como frontend, bajo la metodología ágil Scrum, con entregables funcionales semanales y de forma progresiva a lo largo de 16 semanas[cite: 32].

## Objetivo del Sistema
Diseñar e implementar una aplicación web que permita:
* Registrar productos (bebidas y alimentos)[cite: 32]
* Gestionar ventas, pedidos y cuentas por mesa[cite: 32]
* Controlar el inventario de insumos[cite: 32]
* Generar reportes de ventas[cite: 32]
* Administrar roles de usuarios (mesero, administrador, etc.)[cite: 32]
