# Sistema de Gestión de Bar - Proyecto Académico de Angelo Conterón y Equipo

Este repositorio contiene el desarrollo del sistema de gestión para un bar, elaborado como parte de la asignatura Diseño de Aplicaciones y Servicios de Internet[cite: 2].  
El proyecto se desarrolla usando ASP.NET Core Web API como backend y Blazor WebAssembly como frontend, bajo la metodología ágil Scrum, con entregables funcionales semanales y de forma progresiva a lo largo de 16 semanas[cite: 2].

## Objetivo del Sistema
Diseñar e implementar una aplicación web que permita:
* Registrar productos (bebidas y alimentos)[cite: 2]
* Gestionar ventas, pedidos y cuentas por mesa[cite: 2]
* Controlar el inventario de insumos[cite: 2]
* Generar reportes de ventas[cite: 2]
* Administrar roles de usuarios (mesero, administrador, etc.)[cite: 2]
